# World Radio Translator

Трансляция живых радиостанций со всего мира с синхронным переводом на выбранный язык с помощью AI (Gemini или OpenAI-совместимых сервисов).

## Возможности

- Интерактивная карта мира — кликните, чтобы найти радиостанции в регионе.
- Прямой эфир радио с прокси для CORS/mixed content.
- Поддержка YouTube Live (извлечение аудио).
- Загрузка локальных файлов и захват с камеры/микрофона.
- Перевод голоса в реальном времени: STT → LLM → TTS, с транскриптом.
- Анти-повторы с рифмой, температура 0, без «спасибо»/мусора.
- Редактируемые System/User prompt и температура для OpenAI LLM.
- Ducking и скорость TTS (0.5–2x).
- Буфер источника (0–10 с) с автоматическим замером латентности.
- Экспорт: транскрипт (TXT), аудио (WAV: оригинал / перевод / микс) и субтитры SRT.
- Настройки AI: Gemini (ключ на сервере) или OpenAI-совместимые эндпоинты (LLM/STT/TTS).
- Поиск моделей и тест подключения для OpenAI-совместимых сервисов.
- Сохранение настроек на сервере (по client ID).
- Панель лога действий с таймстемпами и категориями.
- Тёмная/светлая тема, 3 языка интерфейса (EN/RU/DE), 60+ языков перевода.
- Android-приложение (Capacitor) с полным функционалом.

### Фронтенд (`src/`)

- **`App.tsx`** — главный компонент: состояние, тема, выбор станции, живой перевод, транскрипт.
- **`components/`**
  - `WorldMap.tsx` — интерактивная карта (клик по региону).
  - `StationList.tsx` — список радио/YouTube/локальных источников с поиском.
  - `AudioPlayer.tsx` — HTML5 аудио/видео плеер с HLS.
  - `AudioVisualizerD3.tsx` — визуализатор частот.
  - `AIProviderSettingsPanel.tsx` — настройки провайдера, поиск моделей, тест.
- **`services/`**
  - `liveTranslateClient.ts` — захват аудио из DOM, WebSocket-стриминг, воспроизведение перевода, запись WAV.
  - `aiProviderSettings.ts` — загрузка/сохранение настроек (localStorage + сервер).
- **`apiBase.ts`** — разрешение базового URL бэкенда.
- **`i18n.ts` + `locales/`** — локализация (EN/RU/DE).
- **`types.ts`** — интерфейсы TypeScript.

### Бэкенд (`server.ts`)

- Сервер Express с Vite middleware (dev) / static (prod).
- WebSocket-сервер на `/api/live-stream` для реального времени.
- REST-эндпоинты:
  - `POST /api/geocode` — обратный геокодинг + культурный профиль.
  - `POST /api/ai/models` — поиск моделей для OpenAI-совместимых сервисов.
  - `POST /api/ai/test` — тест LLM/STT/TTS эндпоинтов.
  - `GET/POST /api/settings` — серверное хранение настроек.
  - `POST /api/translate` — разовый перевод текста.
  - `POST /api/live-transcribe` — пошаговая транскрипция/перевод аудио.
  - `POST /api/generate-feed` — генерация программных карточек.
  - `GET /api/proxy-stream` — прокси потоков для CORS/mixed content.
  - `GET /api/youtube-stream` / `/api/youtube-search` — извлечение YouTube-аудио.
- Интеграция Gemini через `@google/genai` с повторами и fallback.
- OpenAI-совместимая интеграция: chat completions, audio transcriptions, audio speech.

### Android (`android/`)

Обёртка Capacitor (WebView). Разрешения: INTERNET, CAMERA, RECORD_AUDIO и др.

### Поток данных (живой перевод)

1. Пользователь выбирает станцию и нажимает «Запустить перевод».
2. `liveTranslateClient.connect()` открывает WebSocket на `/api/live-stream`.
3. Сервер инициализирует AI-провайдера (Gemini Live или OpenAI-совместимый пайплайн).
4. Клиент захватывает PCM-аудио из `<audio>`/`<video>` каждую секунду.
5. Аудиочанки отправляются на сервер через WebSocket.
6. Сервер обрабатывает: STT → перевод LLM → TTS.
7. Переведённое аудио + транскрипт отправляются клиенту.
8. Клиент воспроизводит перевод и показывает транскрипт.

## Запуск локально

**Требования:** Node.js 18+

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Задайте `GEMINI_API_KEY` в `.env.local` (необязательно, для Gemini).
3. Запустите:
   ```bash
   npm run dev
   ```
   Откройте http://localhost:3000

## Сборка (production)

```bash
npm run build
NODE_ENV=production PORT=3000 npm run start
```

## Сборка Android

```bash
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`
